# Multi-Language (i18n) Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full multi-language support — UI translation + DM narrative language switching across 5 languages (en, zh-CN, ja-JP, es-ES, ko-KR).

**Architecture:** Lightweight custom i18n runtime (~50 lines) with JSON locale files. No external dependencies. Locale flows: frontend `localStorage` → WebSocket payload → backend Player object → LLM prompt injection. Each player in a multiplayer game gets independent DM narrative language.

**Tech Stack:** Vanilla TypeScript, JSON files, localStorage for persistence, no i18n library.

### Task 4: Frontend i18n Runtime

**Files:**
- Create: `public/js/i18n.ts`

- [ ] **Step 1: Create `public/js/i18n.ts` — lightweight translation runtime**

This module handles locale loading, string interpolation, and DOM language updates. It imports all locale JSON files dynamically.

```ts
// public/js/i18n.ts
import en from "../../locales/en.json";
import zhCN from "../../locales/zh-CN.json";
import jaJP from "../../locales/ja-JP.json";
import esES from "../../locales/es-ES.json";
import koKR from "../../locales/ko-KR.json";

const LOCALES = { "en-US": en, "zh-CN": zhCN, "ja-JP": jaJP, "es-ES": esES, "ko-KR": koKR } as const;

export type SupportedLocale = keyof typeof LOCALES;
type TranslationKeys = keyof (typeof en);

let currentLocale: SupportedLocale = "en-US";

export function initI18n(): void {
  const saved = localStorage.getItem("dnd-locale") as SupportedLocale | null;
  if (saved && saved in LOCALES) {
    currentLocale = saved;
  }
  applyHtmlLang();
}

export function getLocale(): SupportedLocale {
  return currentLocale;
}

export function setLocale(locale: SupportedLocale): void {
  currentLocale = locale;
  localStorage.setItem("dnd-locale", locale);
  applyHtmlLang();
}

function applyHtmlLang(): void {
  const langMap: Record<SupportedLocale, string> = {
    "en-US": "en", "zh-CN": "zh-CN", "ja-JP": "ja", "es-ES": "es", "ko-KR": "ko",
  };
  document.documentElement.lang = langMap[currentLocale] || "en";
}

export function t(key: TranslationKeys, params?: Record<string, string | number>): string {
  const localeData = LOCALES[currentLocale];
  let str = (localeData as Record<string, string>)[key] ?? en[key as keyof typeof en] ?? key;
  if (params) {
    for (const [paramKey, value] of Object.entries(params)) {
      str = str.replace(`{${paramKey}}`, String(value));
    }
  }
  return str;
}

export function getLocaleDisplayName(locale: SupportedLocale): string {
  const names: Record<SupportedLocale, string> = {
    "en-US": "English", "zh-CN": "简体中文", "ja-JP": "日本語", "es-ES": "Español", "ko-KR": "한국어",
  };
  return names[locale];
}

export const SUPPORTED_LOCALES = Object.keys(LOCALES) as SupportedLocale[];
```
